CS Elo — FACEIT Elo участников турнира CS2 (Windows)

КАК ЗАПУСТИТЬ
1. Распакуйте архив (правый щелчок → «Извлечь все»). Из архива без распаковки не запускайте.
2. Дважды щёлкните CS-Elo.exe.
3. В первый раз Windows покажет синее окно «Windows защитила ваш компьютер» —
   программа не подписана платной подписью. Нажмите «Подробнее» → «Выполнить в любом случае».
4. Откроется чёрное окно (это и есть приложение, не закрывайте его) и страница в браузере.
5. Вставьте ссылку на турнир с Liquipedia или HLTV и нажмите «Проверить».
   Если составов на Liquipedia ещё нет — вставьте список команд текстом:
   Команда: игрок1, игрок2, игрок3, игрок4, игрок5
   Слово demo — тестовые данные без интернета.

КАК ВЫКЛЮЧИТЬ
Закройте чёрное окно или нажмите «Выключить приложение» на странице.

ГДЕ ТАБЛИЦЫ
Документы\CS Elo (на странице есть кнопка «Открыть папку с таблицами»).

Python устанавливать не нужно — всё уже внутри CS-Elo.exe.
Проект: https://github.com/ritok1337/cs-turnir
