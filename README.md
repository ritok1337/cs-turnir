cs-turnir — приложение: ссылка на турнир CS2 (Liquipedia или HLTV) → таблица команд и игроков с текущим FACEIT Elo и средним по команде.

## Скачать (macOS)
Готовая сборка: [GitHub Releases → cs-turnir-macos-v0.6.0.zip](https://github.com/ritok1337/cs-turnir/releases/latest). Распакуйте архив; нужен Python 3 (на Mac он ставится вместе с инструментами разработчика Xcode).
Программа не подписана Apple, поэтому при первом запуске: правый щелчок по «Запустить CS Elo.app» → «Открыть» → «Открыть» (или Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»).

## Скачать (Windows)
Готовая сборка: [GitHub Releases → cs-turnir-windows-v0.6.0.zip](https://github.com/ritok1337/cs-turnir/releases/latest). Python ставить не нужно.
1. Распакуйте архив (правый щелчок → «Извлечь все») и дважды щёлкните `CS-Elo.exe`.
2. В первый раз Windows покажет «Windows защитила ваш компьютер» (программа не подписана): «Подробнее» → «Выполнить в любом случае».
3. Откроется чёрное окно (это приложение, не закрывайте его) и страница в браузере. Таблицы — в «Документы\CS Elo».

Сборка `.exe` делается автоматически на GitHub Actions при каждом релизе и перед публикацией проверяется на Windows: тестовые данные, страница, повторный запуск, сохранение таблицы и настоящий запрос к Liquipedia и FACEIT ([.github/workflows/windows.yml](.github/workflows/windows.yml)).

## Как запустить
1. Дважды щёлкнуть «Запустить CS Elo.app» в этой папке — откроется страница в браузере.
2. Вставить ссылку на турнир и нажать «Проверить» (1–7 минут). Слово `demo` — тестовые данные без интернета.
   Если на Liquipedia составы ещё не заполнены (так бывает до начала турнира), вставьте вместо ссылки список команд текстом, по строке на команду: `Команда: игрок1, игрок2, игрок3, игрок4, игрок5` (например, скопировав с HLTV). Пример: [docs/example-retake-s13-teams.txt](docs/example-retake-s13-teams.txt).
   Если ники игроков неизвестны — достаточно названия команды на отдельной строке (например, `ZOTIX`): приложение найдёт команду с таким названием на FACEIT и возьмёт её состав. То же происходит, если на Liquipedia у команды нет состава.
3. Кнопка «Выключить приложение» внизу страницы останавливает его.

Каждая таблица также сохраняется в CSV (открывается в Numbers/Excel): при запуске значком — в папку «Документы → CS Elo» (кнопка «Открыть папку с таблицами» на странице), при запуске из терминала — в `results/`.

## Ключ FACEIT (необязательно)
С бесплатным ключом разработчика FACEIT приложение находит больше игроков (настоящий поиск по нику, как на сайте FACEIT) и для команд, найденных по названию, считает среднее только по основной пятёрке — пяти игрокам, которые чаще всех играли вместе за последние 4 месяца; остальные показываются как запасные.

Как получить: developers.faceit.com → своё приложение → API Keys → тип **Server side**. Вставьте ключ в блок «Ключ FACEIT» на главной странице приложения. Ключ хранится только на вашем компьютере (`Документы/CS Elo/faceit_key.txt`) и отправляется только в FACEIT.

## Как это работает
- Составы берутся со страницы турнира на Liquipedia (тренеры не считаются).
- FACEIT-профиль игрока — из его страницы на Liquipedia (поле faceitdb/faceit), эло — с faceit.com.
- HLTV не пускает программы, поэтому по ссылке HLTV приложение само находит этот турнир на Liquipedia.
- Если у игрока нет страницы или на ней не указан FACEIT, приложение ищет его на FACEIT само: по точному нику и среди друзей тиммейтов (ник может отличаться: 1↔i, 0↔o, приставки).
- Найденный так игрок засчитывается, только если на FACEIT он связан с уже найденными тиммейтами. Если связи нет — эло показано с пометкой «~» и в среднее по команде не входит (чтобы не подставить однофамильца).
- Ник в таблице — ссылка на профиль FACEIT, можно проверить глазами.
- Состав, взятый с FACEIT по названию команды, может включать запасных и бывших игроков, а команд с одинаковым названием бывает несколько — на странице есть ссылка на выбранную команду и на остальные похожие. Команды меньше чем из 4 человек не рассматриваются.
- Для списка, вставленного текстом, страница игрока на Liquipedia ищется по нику и засчитывается, только если на ней указана его команда или он дружит с тиммейтами на FACEIT — чтобы не подставить однофамильца.

## Файлы
- `app/elo_app.py` — весь код (Python 3.9+, без дополнительных библиотек)
- `app/demo_tournament.json` — тестовые данные
- `Запустить CS Elo.app` — значок для запуска (код приложения лежит внутри него)
- `build_app.sh` — пересобирает значок после изменений в `app/`
- `.github/workflows/windows.yml` и `windows/` — сборка и инструкция для Windows
- `results/` — сохранённые таблицы
- `docs/` — скриншоты и пример результата
